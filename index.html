Project Overview

This project visualizes the available fuel-price and taxation information to make comparisons across countries and over time easier to explore.

Problem Statement

Fuel-price and taxation data can be difficult to compare when it is spread across different sources or displayed in large tables. Interactive visuals help organize the information.

Objectives

Explore fuel prices, compare countries and regions, and examine changes and available taxation measures across 2020–2026.

Tools & Technologies

Tableau Public, HTML, CSS, Bootstrap, and Flask.

Why this project matters: Fuel prices influence household expenses, transportation costs, business operations, and the cost of moving goods. Visual comparisons help viewers explore patterns and ask informed questions about the factors behind them.

Project Objectives

Methodology and Workflow

The website provides a presentation layer for the Tableau work. These are typical stages for this type of analysis; exact calculations depend on the dataset and workbook.

1

Data preparation

Review country names, time periods, price values, and taxation measures. Check for missing values, inconsistent labels, and incompatible units.

2

Analysis design

Define questions the data can answer, such as how displayed values differ across countries or change over time.

3

Visual development

Build charts in Tableau with clear titles, labels, units, and time ranges so viewers can interpret comparisons.

4

Dashboard and story

Arrange related visualizations in a dashboard and use the story to guide viewers through the selected comparison.

5

Web integration

Embed the published Tableau views in this responsive HTML page and provide direct links if embedding is unavailable.

6

Review and validation

Check that views open, labels remain readable on mobile and desktop, and conclusions match the workbook.

How to Read the Analysis

Use these prompts while exploring the dashboard and story. They are questions to investigate, not unverified claims about results.

Country comparison

Which countries appear at the top of the comparison? Check the chart title, units, selected period, and filters before interpreting the ranking.

Change over time

Look for increases, decreases, and volatility. Compare equivalent dates and do not assume a change is caused by one factor alone.

Taxation context

Review field definitions and units. Tax structures, subsidies, exchange rates, and market conditions can differ across countries.

Use the story

Follow the story sequence for a guided comparison, then use the dashboard for broader exploration.

Interpretation reminder: Association does not prove causation. Verify the underlying data, definitions, time range, and source notes before presenting numerical conclusions.

Scope, Limitations, and Future Improvements

Project scope

This page presents the Global Fuel Prices and Taxation Trends project, focusing on the published top-three-country comparison and accompanying Tableau views.

The website is a presentation layer; the visualizations and measures are controlled by the published Tableau workbook.

Limitations

  • Results depend on the source dataset's completeness and consistency.
  • Countries may use different reporting practices or units.
  • Embedded views require Tableau Public and internet access.
  • Published URLs or permissions may change independently.

Future improvements

  • Add dataset citations and field definitions.
  • Document data-cleaning and calculation choices.
  • Add accessible descriptions for key charts.
  • Test embeds across devices and browsers.

Technology stack

HTML structures the page, CSS styles content, Bootstrap supports responsive layout, and Tableau Public delivers interactive visuals. Flask can provide a server layer when deployed as a Flask application.
